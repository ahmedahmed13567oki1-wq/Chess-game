Privacy Policy

Chess application

This Privacy Policy applies to the Chess Android application (com.chess.gamehythm), a chess game played against a computer opponent that runs entirely on the user's device.

Information We Collect

The application does not collect, store, or transmit any personal information or usage data. No information is sent to the developer or to any third party.

Gameplay Data

The game, including the computer opponent, runs locally on the device. The current game (board position, move history, and chosen difficulty) is kept only in the application's memory while it is being played and is never uploaded or shared.

The application does not require an account, sign-in, or an internet connection to work.

Permissions

The application does not request any Android permissions.

The application does not request access to the internet, storage, camera, microphone, location, or contacts.

Third-Party Libraries

The application is built with open-source libraries (AndroidX and Jetpack Compose) that operate entirely on the device and do not transmit any data. The application contains no advertising, analytics, or tracking services.

Sharing the Application

The share feature opens the system share sheet in order to send a link to the application only. The application does not access the user's contacts or messages.

Children's Privacy

The application does not collect data from any user, including children.

User Control and Data Deletion

As no data is retained by the developer, there is nothing to delete. Uninstalling the application removes all of its data from the device.

Google Play Data Safety

  • Data collected: None.
  • Data shared with third parties: None.
  • Advertising: None.

Changes to This Policy

This policy may be updated when new features are introduced. The most recent version will be published on this page together with the date of the update.
